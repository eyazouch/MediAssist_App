# 📱 MediAssist – Mobile Medical Management App  

## 📌 Introduction  
Une interface simple et intuitive est la clé d’une application mobile réussie.  
**MediAssist** a été développée pour aider les utilisateurs à **gérer leurs médicaments, rendez-vous et prescriptions médicales** au quotidien, dans un environnement pratique, sécurisé et facile à utiliser.  

---

## 🎯 Objectif du Projet  
L’application **Android MediAssist** permet aux utilisateurs de :  
- Centraliser leurs informations médicales personnelles 👤  
- Suivre leurs traitements et recevoir des rappels 💊  
- Organiser leurs rendez-vous médicaux 📅  
- Stocker et consulter leurs ordonnances 🧾  
- Garder leurs contacts d’urgence à portée de main 🚑  

---

## ⚙️ Fonctionnalités  
- 💊 **Rappels automatiques pour les médicaments**  
- 📅 **Gestion des rendez-vous médicaux**  
- 🧾 **Archivage des ordonnances**  
- 🚑 **Enregistrement des contacts d’urgence**  
- 👤 **Profil utilisateur personnalisé**  
- 📆 **Calendrier médical intégré**  

---

## 🛠️ Technologies  
- **Langage** : Java ☕ + XML  
- **IDE** : Android Studio 🛠️  
- **Base de données** : SQLite 🗄️  
- **Composants Android** : RecyclerView, CardView, NavigationView  

---

## 🗂️ Architecture de l’Application  

### 📌 Base de Données  
L’application s’appuie sur 5 tables principales :  
- **Users** → Informations personnelles  
- **Medications** → Médicaments et rappels  
- **Appointments** → Rendez-vous médicaux  
- **Prescriptions** → Ordonnances  
- **Emergency_Contacts** → Contacts d’urgence  

### 📌 Organisation du Code  
- `activities/` → Écrans principaux  
- `adapters/` → Gestion des listes & vues  
- `database/` → Gestionnaire SQLite  
- `models/` → Entités et objets métiers  
- `utils/` → Fonctions utilitaires  
- `layouts/` → Interfaces XML
